Download the Barraq app for Android

The official app for Android phones and tablets, downloaded directly from this site. One file works on every device running Android 7.0 or newer.

How to install

  1. Download the file. Tap "Download Barraq for Android" and wait for it to finish. If the connection drops, your browser resumes where it stopped.
  2. Open it. From the download notification, or from the Files app in the Downloads folder.
  3. Allow installs from this source. If Android asks, enable "Allow from this source" for the browser you downloaded with. You can turn it off again afterwards.
  4. Install and open. Tap Install, then Open. Because the app comes from outside a store, Google Play Protect may show a notice: choose "More details", then "Install anyway".

Is the app safe?

  • The file is signed with Barraq's own key. Compare the file fingerprint and certificate fingerprint above with what you see on your side to confirm it was not modified.
  • It asks for the Internet permission only, and talks to Barraq's servers over HTTPS (api.baraqapp.com).
  • We distribute the app only from this page. If a file reaches you from anywhere else, do not install it.

Updates

The app does not update itself from a store. When a new version is released we publish it here: download it and install it over the old one, and your account and data stay as they are.

Frequently asked questions

Does it work on iPhone?

An iOS app is not available yet. You can use Barraq from Safari at web.baraqapp.com.

I see "App not compatible" or "App not installed"

Check that your device runs Android 7.0 or newer and has enough free storage, then download the file again in full and compare its fingerprint. If it keeps failing, write to us with your device model and Android version.

How do I check the file fingerprint on my computer?

On Windows: certutil -hashfile baraq-1.0.0.apk SHA256. On macOS or Linux: sha256sum baraq-1.0.0.apk. The output must equal the fingerprint shown above.
